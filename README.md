Опис Завдання
- Вам потрібно створити простий додаток на базі Next.js з використанням TypeScript та Bootstrap. Додаток повинен мати дві основні сторінки: сторінку логіну та сторінку поповнень.

Завдання:

1. Сторінка Логіну:
Створіть форму для логіну, яка містить поля для введення логіну та пароля.
При успішному логіні повертається токен авторизації, який потрібно зберегти в сookies.
Якщо логін успішний, виконайте редірект на сторінку з поповненнями /top-up.
У шапці (navbar) повинна бути кнопка для завершення сесії, яка чистить cookies та перенаправляє користувача на сторінку логіну.


2. Сторінка Поповнень:
- Виводьте список всіх поповнень, включаючи такі дані:
topUpRequest.createDate
user.userName
account.tfAccountId
topUpRequest.amount
- Над таблицею з даними повинні бути присутній блок з фільтрами. Перший фільтр - input пошук(по tfAccountId). Другий фільр - select по user. Третій фільтр - select по account.
- Додайте кнопку "Додати запит", яка відкриває форму для внесення нових поповнень. В формі ми вибираємо account, amount. User додається на основі залогованого користувача в системі. createDate створюэться автоматично. 
- При додаванні нового запиту - оновлюйте сторінку для відображення нового списку поповнень.
- Під таблицею поповнень виводьте загальну суму всіх поповнень.
- Для кожного рядка списку повинна бути можливість видалити або редагувати запит.


Технічні Вимоги
Технології:
- Використовуйте Next.js для створення веб-додатку.
- Використовуйте TypeScript для типізації.
- Просимо зробити валідацію форм на стороні клієнта. Радимо використати React Hook Form і Zod.
- Використовуйте Bootstrap для стилізації компонентів.
- Клас Database: Для зберігання і маніпуляцією даних використовується клас Database, який знаходиться в файлі src/models/database/Database.ts.
Використовуйте серверні компоненти по максимуму, а саме Server Side Rendering там де це можливо.
